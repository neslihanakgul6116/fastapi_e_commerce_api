# 🛒 FastAPI E-Ticaret Web Uygulaması

Bu proje, modern Python teknolojileri kullanılarak geliştirilmiş, tam fonksiyonel ve kullanıcı dostu bir **E-Ticaret Web Sitesi** uygulamasıdır. Hem arka planda hızlı çalışan güçlü bir API mimarisine hem de kullanıcıların rahatça gezinebileceği şık ve modern bir arayüze sahiptir.

---

## ✨ Projede Neler Var? (Öne Çıkan Özellikler)

* **Ana Sayfa ve Kategori Filtreleme:** Ürünleri tümüyle görebilir ya da *Elektronik, Giyim, Ev & Yaşam, Aksesuar* gibi kategorilere göre kolayca filtreleyebilirsiniz.
* **Canlı Ürün Arama Motoru:** Üst menüde yer alan arama çubuğu sayesinde aradığınız ürüne ismine veya içeriğine göre anında ulaşabilirsiniz.
* **Ürün Detay Sayfası:** Herhangi bir ürünün üzerine tıklayarak büyük görseline, açıklamasına ve fiyat detaylarına özel bir sayfada bakabilirsiniz.
* **Dinamik Sepet Yönetimi:** Beğendiğiniz ürünleri sepete ekleyebilir, sepetinizdeki ürün sayısını (rozeti ile) anlık olarak takip edebilir ve sepet sayfasından ürünleri inceleyebilirsiniz.
* **Mobil Uyumlu Tasarım (Hamburger Menü):** Telefon, tablet veya bilgisayar ekranlarında sorunsuz çalışan esnek bir arayüz (Tailwind CSS ile tasarlandı).
* **Favorilerim ve Checkout (Ödeme) Sayfaları:** Eksiksiz kullanıcı deneyimi için tasarlanmış sayfalar.

---

## 🛠️ Kullanılan Teknolojiler

Proje altyapısında sektörde en çok tercih edilen güncel teknolojiler kullanılmıştır:
* **Python & FastAPI:** Hızlı, modern ve güvenilir web API altyapısı.
* **SQLAlchemy & SQLite:** Ürün ve kategorilerin güvenle saklandığı ilişkisel veritabanı.
* **Jinja2:** Python verilerini HTML şablonlarıyla buluşturan şablon motoru.
* **Tailwind CSS:** Modern, şık ve mobil uyumlu tasarımı sağlayan CSS framework'ü.
* **Uvicorn:** ASGI sunucusu (Uygulamanın web üzerinden çalışmasını sağlar).
